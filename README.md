# Projeto Faturamento — Dashboard Power BI

Dashboard em Power BI para análise de dados de faturamento, desenvolvido como projeto de portfólio.

## 🎯 Objetivo

Acompanhar o faturamento da empresa de forma consolidada, permitindo filtrar por ano/mês e por tipo de indicador de venda, com visão de evolução histórica, ranking de clientes e detalhamento por quantidade e valor vendido.

## 📊 Conteúdo do dashboard

- Cartões de resumo: faturamento total, quantidade de produtos e quantidade de clientes
- Faturamento por indicador (venda externa, venda pendente, venda por indicação)
- Evolução do faturamento por ano (2012–2016)
- Ranking de faturamento por cliente
- Tabela detalhada com quantidade vendida, valor e indicador por cliente
- Filtros por Ano/Mês e por Indicador
